что собсна делает код
- Проверяет robots.txt и получает ссылки на карты сайта.
- Читает sitemap Lenta.ru, включая сжатые XML-файлы .gz.
- Находит адреса отдельных новостных публикаций.
- Скачивает HTML каждой разрешённой страницы.
- Использует BeautifulSoup, чтобы извлечь заголовок, дату, рубрику и основной текст.
- Делает случайные паузы между запросами (по умолчанию 2,5–4 секунды).
- Сохраняет статьи в CSV и исключает дубликаты.
